# 백제 역사 체험관 — 사비 백제로 떠나는 시간 여행!

학교의 대형 수평형 터치 테이블에서 학생 1~4명이 함께 즐기는 교육용 백제 역사 체험 프로그램입니다.
하나의 프로그램 안에 네 가지 게임이 들어 있습니다.

| | 게임 | 한 줄 소개 | 모으는 보상 |
|---|---|---|---|
| 1 | **백제 보물 발굴 탐험대** | 손가락으로 흙을 걷어 내며 백제 유물을 발굴해요 | 유물 도감, 박물관 전시 |
| 2 | **백제마을 만들기** | 건물을 끌어다 놓아 사비 시기 마을을 함께 지어요 | 건축 도감 |
| 3 | **백제 십자 낱말풀이** | 가로세로가 엇갈리는 진짜 십자말풀이로 역사 낱말을 맞혀요 | 역사 지식 배지 |
| 4 | **부소산을 막아라!** | 역할을 나누어 부소산성을 지키는 협동 전략 게임(교육용 가상 시뮬레이션) | 방어 임무 배지 |

인터넷, 서버, 설치, 로그인이 모두 필요 없고 Windows PC에서 바로 실행됩니다.
네 게임 모두 **⭐ 백제 탐험 별**과 **📚 백제 역사 도감** 카드를 함께 모으며, 어떤 게임부터 해도 됩니다.

## 1. 실행 방법 (Windows)

### 가장 쉬운 방법
1. `baekje-treasure` 폴더를 PC의 원하는 곳(예: 바탕 화면)에 복사합니다.
2. **`게임 시작.bat`** 을 더블 클릭합니다.
   - Microsoft Edge(없으면 Chrome)가 **주소창 없는 전체 화면 앱 창**으로 열립니다.
   - 주소창·탭이 보이지 않아 학생이 실수로 다른 화면으로 나가지 않고, 기록도 저장됩니다.
   - (Edge의 키오스크 모드는 항상 InPrivate 창으로 열려 끌 때마다 기록이 지워지므로 사용하지 않습니다.)
   - 전체 화면이 풀리면 **F11** 키를 누르세요. 끝낼 때는 **Alt + F4** 를 누릅니다.

### 직접 여는 방법
- `index.html` 을 더블 클릭해 Edge나 Chrome으로 열고 **F11** 키로 전체 화면을 켭니다.
- 선생님 설정의 "전체 화면 켜기/끄기" 버튼을 눌러도 됩니다.
- 시연용으로 특정 게임을 바로 열려면 주소 끝에 `?game=village`(또는 `crossword`, `defense`)를 붙입니다. `&players=2&difficulty=hard` 도 쓸 수 있습니다.

### 권장 환경
| 항목 | 권장 |
|---|---|
| 브라우저 | Microsoft Edge 또는 Google Chrome 최신 버전 (Windows 기본 Edge로 충분) |
| 화면 | 가로형 1920×1080 기준. 다른 해상도·화면비는 자동으로 확대·축소되고 남는 부분은 여백이 됩니다 |
| 입력 | 멀티 터치 모니터/터치 테이블, 또는 일반 마우스(모든 게임을 마우스로 끝까지 할 수 있음) |
| 인터넷 | 필요 없음 (모든 그림·소리·데이터가 폴더 안에 있습니다) |

> 글꼴은 Windows 기본 "맑은 고딕"과 한자 표시용 "바탕"을 사용합니다.

## 2. 체험관 메인 화면

- 가운데 **게임 카드 4장**을 누르면 카드가 커지며 **게임 시작 창**이 열립니다.
  - **난이도**: 쉬움(1~2학년) · 보통(3~4학년) · 어려움(5~6학년)
  - **함께 하는 사람**: 1~4명
  - **▶ 게임 시작**, **📖 게임 설명**, **내 기록**과 받은 배지
- 아래 막대
  - **📚 백제 역사 도감**: 유물·건축·인물·지명·역사 5분류, 48장. 게임에서 새로 알게 된 내용이 카드로 등록됩니다. 카드마다 설명, **알아 두기(불확실한 점)**, **참고 자료**가 있습니다.
  - **⭐ 백제 탐험 별**: 네 게임에서 받은 별의 합계. 같은 단계는 **최고 기록만** 셉니다(같은 단계를 반복해 별을 늘릴 수 없음).
  - **🏛️ 특별 전시**: 별 5개 「사비 도성 한눈에 보기」, 15개 「바다 건너 백제 문화의 길」, 30개 「백제 탐험 명예의 전당(인증서)」
  - **🔊 음량**, **⚙️ 선생님 설정**(3초 누르기)
- 게임 중에는 왼쪽 위 **🏛️ 버튼** → "체험관으로 나가기"로 언제든 메인 화면에 돌아옵니다.
- **한 번에 한 게임만 실행**됩니다. 다른 게임으로 가면 앞 게임은 완전히 멈추고 정리됩니다.
- 한 게임에서 오류가 반복되면 그 게임만 닫고 체험관으로 돌아오며, 다른 게임에는 영향이 없습니다.

## 3. 게임 1 — 백제 보물 발굴 탐험대

체험관에서 1번 카드 → 게임 시작을 누르면 발굴 탐험대 메뉴가 열립니다(왼쪽 아래 "← 체험관으로").

```
유적지 선택 → 흙 걷어 내기 → 유물 발견 → 붓으로 정밀 발굴 → 기록 → 유물 수습
→ 발견 연출 → 탐구 활동 → 역사 퀴즈 → 결과·보상 → 박물관 전시
```

| 스테이지 | 유적지 | 발굴 대상 | 탐구 활동 |
|---|---|---|---|
| 튜토리얼 · 고고학자 훈련소 | 가상의 발굴 연습장 | 연습용 백제풍 토기 조각 4개 (실제 유물 아님) | 조각을 끌어 토기 맞추기 |
| 1 · 능산리 절터의 비밀 | 부여 능산리사지 목탑 터 | 부여 능산리사지 석조사리감 | 새겨진 글자(20자) 관찰 |
| 2 · 왕흥사의 보물 | 부여 왕흥사지 목탑 터 (심초석) | 부여 왕흥사지 사리기 (청동제사리합·은제사리호·금제사리병) | 그릇을 차례로 열어 보고 이름표 맞추기 |
| 3 · 전설의 백제금동대향로 | 부여 능산리사지 (공방 터로 여겨지는 건물터의 진흙 구덩이) | 백제금동대향로 | 봉황·악사·산봉우리·연꽃·용 장식 찾기 |

### 발굴 도구
| 도구 | 특징 |
|---|---|
| ⛏️ **작은 삽** | 넓은 범위의 겉흙을 빠르게 걷어 냅니다. 유물 바로 위의 마지막 흙은 걷지 못하고, 유물 가까이에서 쓰면 **조사 품질 점수가 줄어듭니다.** |
| 🖌️ **발굴 붓** | 유물 주변 흙을 부드럽게 털어 내 모양을 드러냅니다. |
| 🔍 **정밀 붓** | 유물 위의 고운 먼지를 털어 냅니다. 글자·문양이 있는 곳은 **돋보기 효과**로 확대됩니다. |
| 📷 **기록 도구** | 드러난 유물을 누르면 사진 촬영 연출, 출토 위치 깃발(예: `D-3 구획`), 발굴 수첩 기록이 남습니다. |

**완료 조건**: ① 흙 걷기 ② 주변 정리 ③ 먼지 털기 ④ 기록 → 가운데 **"유물 수습하기"** 버튼이 나타납니다.

- 점수: 조심스럽게(조사 품질), 꼼꼼하게(문양 관찰), 함께(협동) 할수록 점수와 별이 늘어납니다.
- 칭호 5단계, 배지 7종(첫 발견, 꼼꼼한 손길, 협동 탐험대, 문양 탐정, 역사 박사, 금빛 전설, 큐레이터)
- **나만의 백제 박물관**: 수장고의 유물을 끌어 전시대에 올리고, 눌러서 돌려 보기·설명·발굴 기록을 봅니다.
- 발굴한 유물은 역사 도감(유물·지명·인물 카드)에도 등록됩니다.

**협동 발굴(2~4명)**: 테이블 네 가장자리에 각자의 도구 구역이 생기고, **기본으로 모두 동시에** 하나의 유적을 팝니다. 체험관 시작 창에서 2~4명을 고르면 바로 동시 협동 발굴의 유적지 선택으로 갑니다.
- 손가락마다 따로 처리되어, 네 명이 동시에 각자 고른 도구(삽·붓·정밀 붓·기록)로 서로 다른 곳을 팔 수 있습니다. 손가락을 처음 댄 위치에서 가장 가까운 가장자리 학생의 도구가 적용됩니다.
- 동시에 파려면 **멀티 터치 화면**이 필요합니다. 마우스는 한 번에 한 곳만 파집니다.
- 멀티 터치가 안 되는 화면에서는 협동 발굴 메뉴나 선생님 설정에서 "순서대로 돌아가며"를 고르세요.

## 4. 게임 2 — 백제마을 만들기

넓은 빈 땅(백마강, 평야, 숲, 부소산 언덕, 도로)에 건물을 끌어다 놓아 사비 시기 마을을 함께 짓는 **아이소메트릭 마을 건설 게임**입니다.

### 조작
| 하고 싶은 일 | 방법 |
|---|---|
| 짓기 | 아래 카드판의 건물 카드를 끌어 지도 위에 놓기. **초록 칸**이면 지어지고 **빨간 칸**이면 이유가 표시돼요(예: "강 위에는 지을 수 없어요") |
| 취소 | 끌던 건물을 카드판 위로 되돌리기 |
| 옮기기 | 지도 위 건물을 끌기 |
| 정보·회전·철거 | 지도 위 건물을 눌러 나오는 창에서 (철거하면 비용 절반 돌려받음) |
| 도로 | 도로 카드를 끌어 칸을 칠하듯 놓기. 도로에 이어지지 않은 건물은 생산이 절반이고 표시가 떠요 |
| 숲 | 숲을 눌러 나무 베기 |
| 되돌리기 | 그 자리 친구가 한 최근 행동부터 차례로(최대 12개) |
| 저장 / 전경 감상 | 💾 저장(자동 저장도 됨) / 🌄 화면 안내를 숨기고 마을을 천천히 둘러보기 |

### 건물 (17종 + 도로)
- 생활: 초가집, 기와집, 우물, 창고, 시장 · 생산: 농경지, 토기 공방, 직물 공방, 대장간
- 문화: 절, 탑, 교육 및 기술 전수 공간 · 주요: 궁궐, 성문, 성벽, 관청, 선착장(강가에만)

### 마을의 움직임
- 자원 4가지(식량, 나무, 흙·재료, 문화 점수)가 3초마다 생산되고, 건물을 지으면 소비됩니다. 시장은 도로로 이어진 공방의 생산을 높여 줍니다.
- 집을 지으면 주민이 나타나 도로를 따라 농경지·공방·시장으로 다니며 말풍선으로 생활 모습을 보여 줍니다.
- 성장 단계: 작은 백제 마을 → 발전하는 백제 마을 → 활기찬 사비 마을 → **찬란한 사비 문화도시**
- 미션 6개(집 세 채, 농경지와 식량, 시장과 도로, 토기 공방, 절과 탑, 성벽과 성문)를 해결하면 새 건물이 열리고, 절·탑과 성벽·성문 미션에서는 역사 이야기 카드가 나옵니다.
- 건물을 처음 지을 때마다 건축 도감 카드가 등록됩니다.
- 난이도: 쉬움(자원 넉넉) · 보통 · 어려움(자원이 적고 주민이 식량을 먹어요)
- 다시 들어오면 **"이어서 하기 / 새 마을"** 을 고릅니다.

> ⚠️ 이 마을은 **교육용 가상 재구성**이며 실제 사비 도성의 정확한 복원도가 아닙니다. 건물 모양 대부분은 유적과 기록을 참고한 **창작 재현**이고, 자원 체계는 게임을 위한 단순화입니다(화면에도 늘 표시됩니다). 수업에서 함께 짚어 주세요.

## 5. 게임 3 — 백제 십자 낱말풀이

가로 낱말과 세로 낱말이 **서로 엇갈리고, 만나는 칸의 글자가 같아야 하는** 진짜 십자말풀이입니다.

### 화면
가운데 낱말 격자판(번호 칸, 빈칸, 쓸 수 없는 칸 구분) · 오른쪽 가로/세로 문제 목록 · 아래 글자 입력판 · 위쪽 진행률·힌트·점수·시간

### 푸는 방법
1. 격자의 칸이나 문제 목록을 눌러 낱말을 고릅니다 → 힌트가 나옵니다.
2. 아래 입력판으로 한 글자씩 입력합니다 → 격자에 글자가 나타납니다.
3. **정답 확인**을 누릅니다. 맞으면 글자가 금빛으로 빛나고(가로·세로 완성 효과음이 다름) 해설과 그림이 나옵니다.
4. 틀려도 정답을 바로 알려 주지 않고 **다시 도전**합니다(두 번째부터 틀린 칸 표시).
5. 맞힌 글자는 엇갈리는 낱말에도 함께 채워집니다. 모두 채우면 금빛 연꽃무늬가 피어나며 퍼즐 완성!

| 입력 방법 | 설명 |
|---|---|
| **글자 타일** (쉬움 기본) | 완성된 글자 타일을 골라 누릅니다 |
| **자음·모음 자판** (보통·어려움 기본) | ㄱ, ㅏ… 를 눌러 글자를 조합합니다(겹받침, 받침 넘김 지원). 「가 / ㄱ」 버튼으로 전환 |
| **실제 키보드** | 한글 입력기로 바로 쳐도 되고, 영문 상태에서도 두벌식 자리로 입력됩니다. Enter=확인, Backspace=지우기 |

버튼: 힌트 보기(한 글자 공개, 점수 -30, 쉬움 5·보통 3·어려움 2번) · 한 글자 지우기 · 입력 취소 · 정답 확인 · ◀▶ 낱말 바꾸기

### 퍼즐 (모두 검사를 통과한 퍼즐)
| 난이도 | 퍼즐 | 낱말 수 | 특징 |
|---|---|---|---|
| 쉬움(1~2학년) | 부소산에 올라요 · 백제 마을과 절 | 5 · 5 | 짧은 낱말, 그림 힌트 |
| 보통(3~4학년) | 사비 도성 한 바퀴 · 웅진에서 사비로 | 8 · 7 | 역사 용어, 설명형 힌트 |
| 어려움(5~6학년) | 사비성의 마지막 이야기 · 사비의 문화유산 | 10 · 10 | 사건·문화유산, 추론형 힌트, 제한 시간 켜기/끄기 |

- **협동(2~4명)**: 가운데 퍼즐은 하나이고, 친구마다 **자기 색깔의 입력판**이 있습니다. 한 친구가 풀고 있는 낱말은 다른 친구가 고를 수 없어 입력이 겹치지 않습니다.
- 퍼즐을 다 풀면 별·점수·역사 지식 배지(🌱 새싹 낱말 탐험가, 📜 백제 역사 탐구가, 🏅 백제 문화유산 박사)와 도감 카드를 받습니다. 중간에 나가도 **이어 하기**가 됩니다.

## 6. 게임 4 — 부소산을 막아라! (백제의 마지막 방어선을 지켜라!)

부소산성 주변 지도에서 적을 상징하는 귀여운 유닛이 길을 따라 성문으로 옵니다. 방어 시설을 배치하고 자원을 나누어 성문을 지키는 **협동 전략 게임**입니다. 잔혹한 표현은 없으며, 막힌 유닛은 흰 깃발과 연기 효과를 남기고 **후퇴**합니다.

### 진행
준비 시간(시설 설치·이동) → **✋준비** → 정찰 담당이 **🚩공격 시작** (준비 시간이 끝나면 자동 시작) → 웨이브 → 다음 웨이브

| 방어 시설 | 하는 일 |
|---|---|
| 🏹 활쏘기 진지 | 범위 안의 적을 저지. 가벼운 적에게 효과적. 3단계 강화 |
| 🧱 성벽 | 길 위 자리에 놓아 적을 멈춰 세움. 부서지면 수리 |
| 👀 감시초소 | 다음 웨이브의 방향과 구성을 미리 보여 줌, 주변 진지 범위 증가, **정찰병을 보이게 함** |
| 🌾 보급 창고 | 웨이브가 끝날 때마다 자원 공급 |
| 🚪 성문 | 지켜야 할 곳. 내구도가 0이 되면 그 단계 실패 |

| 적 | 특징과 대응 |
|---|---|
| 일반 보병 | 기본 |
| 방패병 | 화살에 강함 → 진지 강화, 성벽 |
| 정찰병 | 빠름, 감시초소 근처에서만 보임 |
| 공성 수레 | 느리지만 튼튼, 성벽·성문을 크게 흔듦 |

단계: ① 성문을 지켜라(연습 안내) ② 숲길을 방어하라 ③ 무너진 성벽을 고쳐라 ④ 보급품을 지켜라 ⑤ 부소산 최후의 방어(성공 시 🛡️ **백제 수호자**)

- 시설 조작: 카드를 끌어 설치 · 준비 시간에 옮기기 · 눌러서 강화/수리/판매(준비 중 전액, 웨이브 중 절반 환불) · 범위 표시 · 비용 표시 · 🔍 확대·축소(확대하면 끌어서 이동) · ⏸ 일시정지 · 1×/2× 속도
- **4인 역할**: 1 성벽 관리(아래) · 2 방어시설 관리(위) · 3 보급 관리(왼쪽) · 4 정찰 및 전략(오른쪽). 1명이면 모든 역할, 2명이면 (성벽+보급)/(방어시설+정찰), 3명이면 (성벽+보급)/방어시설/정찰.
- 각 단계가 끝나면 **"🎮 교육용 시뮬레이션(게임 속 이야기)"** 과 **"📜 실제 역사 기록"** 을 나누어 보여 줍니다.

> ⚠️ 이 게임의 방어 성공은 **교육용 가상 시뮬레이션**이며 특정 전투가 그대로 있었음을 주장하지 않습니다. **실제 백제는 660년 신라·당 연합군의 공격으로 사비성이 함락되어 멸망했습니다.** 시설과 규칙은 이해를 돕기 위한 단순화이며 실제 백제의 전술·장비를 재현한 것이 아닙니다.

## 7. 멀티 터치와 협동

- 모든 게임은 Pointer Events로 **손가락(pointerId)마다 따로** 입력을 처리합니다. 여러 명이 동시에 끌어도 서로의 작업이 섞이지 않고, 같은 건물·같은 낱말을 두 사람이 동시에 잡을 수는 없습니다.
- 손가락이 갑자기 떨어지거나 화면 밖으로 나가도(pointercancel) 끌던 상태가 정리됩니다.
- 플레이어 색: 빨강(아래) · 파랑(위) · 초록(왼쪽) · 보라(오른쪽). 각자 자리 쪽으로 글자가 돌아가 있습니다.
- 프로그램은 화면이 실제로 몇 개의 터치를 동시에 지원하는지 보장하지 않습니다. 터치 수는 모니터와 드라이버에 따라 다릅니다.

## 12. 검증 상태

### 개발 중 확인한 것 (Chrome 자동 실행, 마우스·가상 터치 입력)
- 메인 화면 4종 카드 표시, 각 게임 독립 실행, 게임 사이 전환 시 앞 게임 정리(남은 화면·반복 실행 없음), 메인 메뉴 복귀
- 게임 오류가 반복되면 그 게임만 닫히고 체험관으로 돌아옴
- 발굴: 기존 자가 진단 37항목 모두 통과(선생님 설정 → 자가 진단 실행으로 다시 확인 가능)
- 마을: 두 명이 동시에 카드를 끌어 건물 2채 건설, 자원 생산·소비, 주민 등장·이동, 미션 6개·성장 4단계, 되돌리기, 저장·이어서 하기
- 낱말: 6개 퍼즐 모두 끝까지 풀기, 한글 조합 35개 검사 통과, 실제 키보드 입력, 오답 재도전, 엇갈리는 글자 반영, 두 명 동시 입력과 낱말 잠금, 이어 하기, 새 퍼즐 검사
- 방어: 네 손가락 동시 끌기로 시설 4개 설치, 설치 가능 판정, 비용 차감, 길 따라 이동, 방패병·정찰병·공성 수레 판정, 수리·강화·판매, 성문 0 → 실패, 승리 → 보상 저장, 단계 열림. 아무것도 안 하면 모든 단계에서 지고, 기본 전략으로 쉬움·보통 전 단계 통과
- 게임별 저장 유지, 180° 화면 회전, 인터넷 없이 실행

### ⚠️ 실제 터치 테이블에서 확인이 필요한 것
- 실제 손가락 2~4개를 **동시에** 쓸 때의 반응(모니터가 지원하는 동시 터치 수, 손바닥 인식으로 생기는 터치 취소)
- 옆자리(왼쪽·오른쪽) 학생에게 버튼 크기·글자 방향이 편한지, 마을 게임 2인 이상일 때 작은 칸(약 62px)을 누르기 쉬운지
- 낱말풀이에서 Windows 실제 한글 입력기와 화면 터치 키보드가 함께 뜨지 않는지
- 방어 게임 확대 상태에서 끌다가 화면이 잘못 밀리지 않는지
- 실제 스피커의 소리 크기

## 13. 문제 해결

| 증상 | 해결 |
|---|---|
| 소리가 나지 않아요 | 브라우저 정책상 **첫 터치 이후**부터 소리가 납니다. 메인 화면 아래 음량과 선생님 설정을 확인하세요. |
| 화면이 확대되거나 밀려요 | `게임 시작.bat`(전체 화면 앱 창)으로 실행하세요. |
| 터치 위치가 어긋나요 | 브라우저 확대 비율을 100%(Ctrl+0)로 맞추고, Windows 터치 보정(제어판 → 태블릿 PC 설정 → 보정)을 확인하세요. |
| 테이블의 반대쪽이 화면 "아래"예요 | 선생님 설정 → 화면 방향 → 180° 회전 |
| 화면이 끊겨요 | 선생님 설정 → 그래픽 품질 → 성능 우선 |
| 여러 명이 동시에 안 돼요 | 화면이 멀티 터치를 지원하지 않는 경우입니다. 발굴은 "순서대로 돌아가며"를 쓰고, 다른 게임은 한 사람씩 번갈아 조작하세요. |
| 게임 카드가 흐리게 잠겨 있어요 | 선생님 설정 → 체험관 설정에서 "사용"으로 바꾸세요. "불러오지 못했어요"가 보이면 `js/games/` 폴더의 파일이 있는지 확인하세요. |
| 기록이 저장되지 않아요 | "인터넷 사용 기록 삭제"나 InPrivate 창에서는 저장이 유지되지 않습니다. 저장할 수 없어도 게임은 멈추지 않고 그 실행 동안만 기록을 유지합니다. |
| 화면이 멈췄어요 | 왼쪽 위 🏛️ → 체험관으로 나가기. 그래도 안 되면 F5(기록은 남습니다). |

## 14. 폴더 구조

기존 발굴 게임의 구조를 그대로 두고, 새 게임은 `js/games/` 에 모듈로 추가했습니다.

```
baekje-treasure/
├─ index.html              화면 구성 (체험관·발굴·게임 자리)
├─ style.css               공통 디자인 · 발굴 게임 디자인
├─ app.js                  화면 전환·발굴 흐름·점수·저장·선생님 설정·자가 진단
├─ css/
│  ├─ hub.css              체험관 메인·도감·특별 전시
│  ├─ village.css / crossword.css / defense.css
├─ js/
│  ├─ hub.js               체험관 관리자 (게임 등록·실행, 공통 보상, 도감, 오류 격리)
│  ├─ games/
│  │  ├─ village.js        백제마을 만들기
│  │  ├─ crossword.js      백제 십자 낱말풀이 (퍼즐 검사기·한글 조합기 포함)
│  │  └─ defense.js        부소산을 막아라!
│  ├─ dig.js               발굴 엔진
│  ├─ art.js               유물 일러스트
│  ├─ activities.js        발견 연출·탐구 활동·퀴즈
│  ├─ museum.js            나만의 백제 박물관
│  └─ audio.js             효과음 (Web Audio로 직접 합성 — 외부 음원 없음)
├─ data/                   artifacts · questions · stages · historyCards · buildings · crossword · defenseStages (.json), data.js (자동 생성)
├─ assets/                 로고, 아이콘(SVG), custom/(선생님 등록 사진)
├─ docs/GAME_API.md        게임 모듈 연결 규약 (새 게임을 추가할 때)
├─ tools/build-data.ps1    data.js 생성 스크립트
├─ 데이터 갱신.bat          JSON 수정 후 실행
├─ 게임 시작.bat            주소창 없는 전체 화면으로 실행
└─ README.md
```

### 기술 메모 (개발·유지보수용)
- 설계 해상도 1920×1080 무대를 `transform: scale()` 로 화면에 맞추고, 터치 좌표는 역변환으로 계산합니다(180° 회전 포함). 새 게임도 같은 변환 함수(`host.mapPoint`)를 씁니다.
- 모든 스크립트는 일반 `<script>` 로 불러와 `file://` 더블 클릭 실행에서도 동작합니다. 게임 파일 하나가 없어도 나머지는 동작합니다.
- 게임 모듈은 `BaekjeHub.register({ id, mount(root, host) })` 로 등록하고, 체험관은 한 번에 하나만 `mount` 하며 나갈 때 `unmount` 로 반복 실행·이벤트를 정리합니다. 자세한 규약은 `docs/GAME_API.md`.
- 저장(localStorage): 발굴 `baekje-treasure.save.v1`, 설정 `baekje-treasure.settings.v1`, 체험관 공통 `baekje-hub.save.v1`, 게임별 `baekje-hub.game.<게임>`, 카드 수정 `baekje-hub.cardOverrides.v1`.
- `index.html?selftest=1` 로 열면 발굴 자가 진단을 실행하고 결과를 창 제목과 화면에 표시합니다.
