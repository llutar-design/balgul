이 폴더에는 선생님이 사용 권한을 확인한 유물 이미지를 넣을 수 있습니다.

방법 1) 게임 안에서 등록 (권장)
  화면 모서리 3초 길게 누르기 → 선생님 설정 → "유물 이미지 등록" → 사진 고르기

방법 2) 파일로 등록
  1. 이 폴더에 이미지(png, jpg)를 넣습니다. 예: hyangno.png
  2. data/artifacts.json 에서 해당 유물에 "image": "assets/custom/hyangno.png" 줄을 추가합니다.
  3. "데이터 갱신.bat" 을 실행합니다.

주의: 박물관 등 외부 사진은 사용 허락(공공누리 유형 등)을 확인한 뒤에만 사용하세요.
등록한 사진은 발견 화면과 박물관에 표시되며, 발굴 판정에는 직접 그린 그림의 모양을 사용합니다.
